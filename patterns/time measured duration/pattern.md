**Purpose**: Represent the duration of a process and mention that the provenance of the value is a measurement  

The process itself is a complex entity involving participants, changes and time. It's "time aspect" is a one dimensional temporal region, in this case an uninterrupted one, a temporal interval. (A soccer game could have several such temporal intervals for the two half times plus the stoppage times.) The occupies temporal region-relation of the process to the temporal interval is functional, meaning that this is the sole and identity defining temporal interval of the process. The duration of the temporal interval is quantified using a duration, which is a subclass of value specification. By stating that this duration/value specification is a "has value specification" (sub-property of has part) of a measurement, the provenance of this value specification becomes clear.
