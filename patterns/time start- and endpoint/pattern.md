**Purpose**: Represent and quantify the start and endpoint in time of a process 

The process itself is a complex entity involving participants, changes and time. It's "time aspect" is a one dimensional temporal region, in this case an uninterrupted one, a temporal interval. The occupies temporal region-relation of the process to the temporal interval is functional, meaning that this is the sole and identity defining temporal interval of the process. The temporal interval is bounded by two temporal instants, which are quantified by data properties of type time:inXSDDateTimeStamp.  
Note: Besides speaking about the "time-only-aspect" of processes, processes themselves can also co-exist (bfo:existsAt), be aranged in sequences (bfo:precedes) and be bounded by process boundaries (ro:starts with, ...).
